How a build gets opened

  1. Unpack the container

    Unreal IoStore v11, REDengine, Unity, LÖVE2D or a studio's own engine. The build opens where it ships.

  2. Translate every string

    Dialogue, interface, tooltips, item text. One glossary fixes one word for one thing before the first string is written.

  3. Repack the build

    The files go back into the original container and install natively. We play the running game and send captures at 1280×720 and 1920×1080.

Which game engines can you open?

Unreal Engine, IoStore v11 included; REDengine; Unity; LÖVE2D/LuaJIT; and the in-house engines behind PlatinumGames and Supergiant titles. An unfamiliar format is opened before we quote.

Which build do I send?

The store link and the public build. Nothing else.

Do you sign an NDA for a build?

Yes, before any file changes hands. The first audit does not need one: it only reads the build everyone can download.

Who translates the strings?

An agent system built in-house does the volume. One person sets the glossary, reads every string in context and signs off the final pass.
