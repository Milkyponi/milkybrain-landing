Demo Sprint

// Questions

Before you send anything

Is my engine supported?+
Probably. We have opened and repacked Unreal Engine (IoStore v11, not the old .pak drag-and-drop), REDengine, Unity, LÖVE2D/LuaJIT, and the in-house engines behind PlatinumGames and Supergiant titles. If yours is unfamiliar, we open the format and quote after that — format is never the reason we say no.
Which files should I send?+
For the audit: the store link and the public build, nothing else. For a sprint: the text container as it ships, or an exported string table if you already have one. If extracting it is the problem, that is part of the work — say so and we handle it.
How long does it take?+
Audit in 48 hours. Demo Sprint in 7 days for up to 5,000 words. Full game in 14–21 days. The clock starts when the deposit lands, not when we agree on scope.
Can you sign an NDA?+
Yes, before any file changes hands. The first audit does not need one, because it only reads the public build. Source access, unreleased builds, and marketing plans stay under NDA from the first message.
